Follow one action

  1. Open the running observation console. Confirm INTACT and the shared run ID.
  2. Select a recent neural event in the activity feed. This opens an observer-only recorded window.
  3. Inspect the exact input PNG, sampling bands, contrast encoding, PRC drives and all 47 activity rows. Select any source neuron to see its trace and incoming connections.
  4. Read M, the six-motor mean, and D, MN3_r minus MN2_r. Below M=0.500 there is no action. The observation profile uses D≥0.008 for +48 px, otherwise −48 px of wheel movement. Check actual displacement: a scroll boundary can block a valid command. The older point/click benchmark has separate action phases.
  5. Check the command ID, model steps, timestamps, trusted browser events and before/after hashes in the causal-chain record.
  6. Return to the current session. Replay never executes an action; the backend continued while you inspected.

Timing and observation

One captured image is integrated for 600 steps × 0.01 model seconds. The live runner takes at least 3 wall seconds per window. Actions and capture add overhead. All observers share one backend session. The display interpolates received states and freezes on disconnection; it never invents missing neural activity.

Episodes end at a fixed budget, followed by a labelled supervisor reset. Browser failure triggers a recorded recovery. The evaluator never reaches the controller. Raw evidence is retained locally for eight episodes; compact records are published by Specimen Recorder with actual commit receipts and duplicate prevention.
