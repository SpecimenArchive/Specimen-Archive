# Specimen Archive — assessment companion

This material sits outside the laboratory narrative used by the website and public archive. It explains the medium, implementation and limits for assessors. The public presentation speaks as the laboratory operating Specimen 01; that voice does not change the evidence below.

## Medium and scientific scope

Specimen Archive is a fictional laboratory exhibit built around a computational digital organism. The apparatus and microscopy-style specimen plates are generated imagery. They are not photographs of a living specimen or a named research laboratory. The specimen’s existing renderer deforms that plate using the recorded motor and pose state. Its illustrative field landmarks are not registered neuron positions. Original asset prompts, source references and licences remain in the [data provenance](DATA_PROVENANCE.md), [photographic rig](PHOTOGRAPHIC_RIG.md), [apparatus record](APPARATUS_LABELS.md) and [third-party notices](../THIRD_PARTY_NOTICES.md).

Published *Platynereis dumerilii* anatomy supplies a selected **47-cell circuit, 161 connections and 711 anatomical synapses**. The full imported reference graph contains 2,675 nodes and 14,066 edges; only the selected subset is active. Positive effective signs, non-spiking rate dynamics, gains, time constants, visual encoding and motor mapping are engineering assumptions. This is not a validated whole-animal replica, biological neural recording or demonstration of consciousness. Dimensionless activity is neither spike rate nor measured membrane voltage. The [methods](METHODS.md) retain equations and assumptions.

## Actual execution and ownership

Chrome runs on the dedicated Windows 11 VM. Native Windows capture and input receipts are genuine software execution. The home computer and visitors’ browsers are observers.

| Function | Actual implementation |
| --- | --- |
| Sensory input | Exact captured page pixels are converted into contrast-based numerical drive. |
| Neural wheel control | The selected rate circuit feeds the fixed motor gate and direction decoder. |
| Destination and pointer placement | A conventional supervisor chooses approved URLs and places the input cursor. |
| Persistent exploration | Stored visits, discovered links, unresolved questions and cooldowns influence supervisor ranking. |
| Memory storage and retrieval | Conventional software links page identity, coarse image features, actions and outcomes. Retrieval and actual use are recorded separately. |
| Journal | A separate OpenAI narrator interprets bounded source excerpts and actual records, with supporting passages and evidence checks. It may propose an approved destination, but cannot dispatch browser input. |
| Publishing | A separate SYSTEM recorder uses the dedicated deploy key outside the browser controller. It publishes compact evidence to `specimen-records` using normal pushes. |

No wallet connection, signing, trading or posting is enabled. A URL/title match is identity lookup, not proof of visual recognition. Memory storage, narrative fluency and varied destinations do not establish neural learning or biological understanding.

## Results and limits

- The held-out memory comparison found **no measured improvement**: baseline, frozen adaptation and disabled adaptation each produced **113 movements in 144 attempts**, with 31 boundary no-ops per condition. The frozen adapter retains 257 training outcomes. [Protocol and result](MEMORY_EXPERIMENT.md).
- The external pathway audit recorded 15/15 intact wheel proposals; disconnecting sensory outputs or clamping motors yielded 0/15 each. All 45 decisions and 2,700 neural samples replayed exactly. These test the engineered pixel-to-proposal pathway. Native receipts separately establish dispatch and observed displacement. [Control audit](EXTERNAL_CONTROL_AUDIT.md).
- The prior laboratory acceptance measured 601.563 seconds, 1,971 matching two-observer packets, 202 paired checks, 23 visits, 22 URLs and 17 memory-influenced selections. Those are historical results from the interval and revisions named in the report, not new measurements from a copy edit. [Laboratory verification](LABORATORY_REFINEMENT.md).
- Failed receipts, capture interruptions and unsuccessful reviews remain retained. A cold Windows reboot still requires manual console login. Closing RDP alone does not stop the running console session. [Deployment](PUBLIC_DEPLOYMENT.md).
