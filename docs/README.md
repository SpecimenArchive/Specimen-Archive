## Sources and conservation

[Data provenance](DATA_PROVENANCE.md) records published anatomy, graph transformations and attribution. The [apparatus register](APPARATUS_LABELS.md) preserves the marker inscriptions and plate history. [Third-party notices](../THIRD_PARTY_NOTICES.md) retain source licences and asset provenance.

Earlier briefs, development reports and test fixtures remain as dated technical records. They document the station’s construction and unsuccessful attempts; they are not the current operating guide. Original commits and numerical evidence are preserved.
