# Follow a real action

The designed [Inside the system](https://specimenarchive.com/inside) page selects an actual completed decision. Its Capture, Sense, Compute, Decode, Execute and Remember tabs inspect that same saved record. Inspection does not send input or rerun the controller.

| Stage | Actual implementation | Evidence |
| --- | --- | --- |
| Capture | `scripts/windows/remote-worker.ts`, `server/exhibit/remote-desktop.ts`, native Windows helper | Full desktop exposure, pixel agreement check, timestamp and exact sensory crop |
| Sense | `server/exhibit/observation-encoder.ts` | PNG-only upper/lower contrast encoding and left/right drive |
| Compute | `server/model/engine.ts`, `server/model/network.ts` | 600 fixed 0.01-second steps and 60 retained samples per decision; 47 cells, 161 measured connections, 711 anatomical synapses |
| Decode | `server/exhibit/controller.ts` | Motor mean/contrast and fixed wait or ±48 px wheel proposal |
| Execute | `server/exhibit/external-station.ts` | Proposed, accepted, dispatched, acknowledged and observed times; trusted event and actual scroll displacement |
| Remember | `server/memory/store.ts` | Stored identity, retrieved/used IDs, matching method and retry-adapter checkpoint |
| Plan and narrate | `server/exhibit/research-planner.ts`, `server/journal/` | Separate navigation proposal, owner, objective, source/memory support and transition receipt |

The six motor cells' mean below 0.5 produces a wait. Above that gate, activity contrast between cells 1732111 and 359142 is compared with 0.008 to select wheel direction. The fixed supervisor pointer is at 40% width, 70% height of the calibrated visible page. The circuit does not select that point, the website, a token or a financial action. DOM observations verify execution and supply semantic context outside the neural input path.

The published imported graph contains 2,675 nodes and 14,066 edges; these are not all simulated. Effective signs, gains, rate dynamics, encoding and decoding are engineering assumptions. Generated apparatus/specimen imagery is distinct from genuine Windows capture and computed activity. See [Methods](METHODS.md) and [data provenance](DATA_PROVENANCE.md).

The apparatus and direct view use one decoded full-desktop frame. Specimen and neural instruments share the presented run/model step; page captions follow that presented context while a new image decodes. A stale/disconnected observer holds its last complete presentation. Display sampling has its own cadence and does not insert extra neural decisions.

Native replay recomputes the model from every recorded PNG and compares the saved states, commands and receipts. Earlier held-out causal controls and the negative learning result remain documented in [EXTERNAL_CONTROL_AUDIT.md](EXTERNAL_CONTROL_AUDIT.md) and [MEMORY_EXPERIMENT.md](MEMORY_EXPERIMENT.md). New showcase verification is separate in [SHOWCASE_VERIFICATION.md](SHOWCASE_VERIFICATION.md).
